## 🌟 Featured Projects

### 🌍 DisSModel — Discrete Spatial Modeling Ecosystem
> **Modern, modular, and open-source alternative to TerraME** for Cellular Automata & System Dynamics modeling in Python.

<p align="center">
  <a href="https://dissmodel.github.io/">🌐 Website</a> • 
  <a href="https://github.com/dissmodel">📦 Organization</a> • 
  <a href="https://pypi.org/project/dissmodel/">📦 PyPI</a> • 
  <a href="https://lambdageo.github.io/dissmodel/">📚 Documentation</a>
</p>

#### 🔧 Core & Infrastructure
| Repository | Description | Status |
|------------|-------------|--------|
| **[dissmodel-core](https://github.com/dissmodel/dissmodel)** | Modular Python framework for CA & System Dynamics with dual Vector/Raster architecture | ✅ Stable |
| **[dissmodel-platform](https://github.com/dissmodel/dissmodel-platform)** | Scalable execution layer using FastAPI + Redis + Docker for simulations-as-a-service | 🔄 Active Dev |

#### 🧩 Domain-Specific Extensions
| Repository | Application Domain | Status |
|------------|-------------------|--------|
| **[dissmodel-ca](https://github.com/dissmodel/dissmodel-ca)** | Classic Cellular Automata models library | ✅ Active |
| **[dissmodel-sysdyn](https://github.com/dissmodel/dissmodel-sysdyn)** | Compartmental models for epidemiology, ecology (SIR, etc.) | ✅ Active |
| **[coastal-dynamics](https://github.com/dissmodel/coastal-dynamics)** | Coastal flooding & mangrove migration models for Maranhão, Brazil | ✅ Active |

> 💡 **Why DisSModel?** Reproducible, interoperable, and cloud-ready geospatial modeling — designed for the next generation of environmental simulations.

### 🏛️ LambdaGeo — Geospatial Semantic Web Research
> **Open tools for Geospatial Linked Data, semantic integration, and reproducible geoinformatics.**

<p align="center">
  <a href="https://lambdageo.github.io/">🌐 Website</a> • 
  <a href="https://github.com/LambdaGeo">📦 Organization</a>
</p>

| Repository | Purpose | Tech Stack |
|------------|---------|------------|
| **[qgissparql](https://github.com/LambdaGeo/qgissparql)** | Bridge QGIS layers with SPARQL endpoints for semantic querying | Python, QGIS, RDFLib |
| **[rdfmapper](https://github.com/LambdaGeo/rdfmapper)** | Declarative Object-RDF mapper for Python (like SQLAlchemy for Linked Data) | Python, RDF, SPARQL |
| **[DBCells](https://github.com/LambdaGeo/dbcells)** | Publish spatial modeling outputs as Linked Open Data (LOD) | Python, RDF, Flask |

> 🔗 **Research Focus**: Interoperability between traditional GIS and Semantic Web standards (RDF, OWL, SPARQL).
