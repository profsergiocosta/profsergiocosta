## 📌 Sobre este perfil

Aqui no `profsergiocosta` eu publico só **projetos pessoais, hobby e experimentos** — não é onde fica o código de pesquisa nem o material didático das disciplinas. Se você está procurando:

- Pesquisa em modelagem geoespacial e LUCC → **DisSModel**
- Semântica geoespacial, Linked Data, plugins QGIS → **LambdaGeo**
- Material de compiladores/linguagens de programação → **LambdaGeo Edu**

O que sobra por aqui é principalmente forks de projetos de terceiros que eu uso ou estudei, e alguns projetos de hobby (jogos, experimentos soltos).
